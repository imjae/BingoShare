# BingoShare

커스텀 빙고판을 만들어 **링크 하나로 공유**하고, 각자 진행하면서 서로의 현황을 보는 웹앱.

**▶ https://imjae.github.io/BingoShare/**

- 설계: [Docs/PLAN.md](Docs/PLAN.md)
- 배포: [Docs/DEPLOY.md](Docs/DEPLOY.md)

## 현재 상태

**링크 하나로 같이 논다. 서버가 없다** — 설정이 링크 주소 안에 통째로 들어간다.

### 방식 두 가지

| | 하나의 판 공유 | 각자 판 만들기 |
|---|---|---|
| 문항을 정하는 사람 | 만든 사람 | **참가자 각자** |
| 링크를 받으면 | 이름 적고 바로 시작 | 이름 적고 **내 문항을 채운 뒤** 시작 |
| 링크 길이 | 문항 24개에 약 520자 | **약 80자** |

### 규칙

- **N줄을 먼저 만든 사람이 승리.** N은 판을 만들 때 정한다
- 판 크기 3×3 / 4×4 / 5×5, 가운데 공짜 칸(홀수 크기만)
- 하나의 판 공유 모드는 참가자마다 칸 섞기 on/off. 켜면 이름에 따라 배치가 정해져 새로고침해도 그대로다
- 문항을 칸 수보다 많이 넣으면 사람마다 뽑히는 문항까지 달라진다
- 가로·세로·대각 빙고 판정, 완성된 줄 강조

아직 없는 것: **다른 사람의 현황판.** 지금은 앱이 "내가" 조건을 채웠다는 것까지만 안다.
누가 먼저였는지는 같이 하는 사람끼리 확인해야 한다. 자동 판정은 M2의 몫이다.

## 실행

```
npm install
npm run dev
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 (타입 검사 포함) |
| `npm run preview` | 빌드 결과를 그대로 띄워보기 |
| `npm run lint` | oxlint |
