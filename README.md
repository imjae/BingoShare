# BingoShare

빙고판 설정을 **링크 하나로 보내면**, 받은 사람이 각자 자기 판을 채워서 노는 웹앱.
판은 각자의 기기에 저장되고, **한 번 열어 둔 뒤에는 인터넷 없이도** 고치고 체크할 수 있다.

## 현재 상태

**서버가 없다.** 판 설정은 링크 주소 안에, 내 판은 내 기기 안에 있다.

### 흐름

1. **보내는 사람** — 제목, 판 크기, 승리 조건(N줄)을 정해 초대 링크를 만든다
2. **받은 사람** — 링크를 열고 이름을 적은 뒤, 빈 판에서 **칸을 눌러 자기 문항을 채운다**
3. **진행** — 칸을 눌러 체크한다. 진행 중에도 언제든 **문항 고치기**로 돌아가 고칠 수 있다

바뀔 때마다 바로 저장된다. 저장 버튼은 없다.

### 규칙

- **N줄을 먼저 만든 사람이 승리.** N은 링크를 만들 때 정한다
- 판 크기 3×3 / 4×4 / 5×5
- 가로·세로·대각 빙고 판정, 완성된 줄 강조
- 문항을 고쳐도 체크한 칸은 그대로 남는다

### 오프라인

처음 한 번 링크를 열 때 앱을 통째로 받아 둔다(서비스 워커). 그 뒤로는 인터넷이 없어도
**같은 브라우저에서** 링크를 다시 열거나 처음 화면의 **"이 기기에 저장된 판"** 목록에서 열 수 있다.

### 한계

- **누가 먼저 이겼는지는 앱이 모른다.** 서버가 없어 남의 판을 볼 수 없다. 같이 하는 사람끼리 확인한다
- 판은 **그 브라우저에만** 있다. 카카오톡 안에서 연 판은 크롬·사파리에서 보이지 않는다
- 사생활 보호(시크릿) 모드에서는 저장되지 않는다. 그럴 땐 화면에 경고가 뜬다

## 실행

```
npm install
npm run dev
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 (서비스 워커는 켜지지 않는다) |
| `npm run build` | 프로덕션 빌드 (타입 검사 포함) + `dist/sw.js` 생성 |
| `npm run preview` | 빌드 결과를 그대로 띄워보기 — 오프라인 확인은 여기서 |
| `npm run lint` | oxlint |
| `npm test` | 단위 테스트 (vitest) |
